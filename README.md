# Bible School Study Buddy

Mobile-first Next.js quiz app for three courses:

- Acts
- Path to Righteousness
- Family Life

Questions live in `src/data/questions.json`. The app shuffles each course deck and loops endlessly. Missed questions come back sooner.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Tap the bottom tabs anytime to switch courses.
